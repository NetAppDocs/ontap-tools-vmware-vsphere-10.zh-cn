= 部署 ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
将 ONTAP tools for VMware vSphere 部署为支持 NFS 和 VMFS 数据存储的超小型单节点设备。部署过程最多需要 45 分钟。

.开始之前
如果部署超小型单节点配置，则内容库是可选的。对于多节点或 HA 部署，需要内容库。

在 VMware 中，内容库存储 VM 模板、vApp 模板和其他文件。使用内容库可简化部署，因为它在模板操作期间不依赖于直接网络访问。

在创建内容库之前：

* 在共享数据存储上创建内容库，以便集群中的所有主机都可以访问它。
* 在部署 ONTAP tools for VMware vSphere OVA 之前，请先创建内容库。
* 部署后，将 OVA 模板保留在内容库中。



NOTE: 如果您计划稍后启用 HA，请将 ONTAP tools 虚拟机部署在 ESXi 集群或资源池中，而不是直接部署在 ESXi 主机上。

要创建内容库，请执行以下操作：

. 从 https://mysupport.netapp.com/site/products/all/details/otv10/downloads-tab["NetApp 支持站点"^]下载 ONTAP tools for VMware vSphere 二进制文件（_.ova_）和签名证书。
. 登录到 vSphere 客户端。
. 在 vSphere Client 菜单中，选择*内容库*。
. 选择 *Create*。
. 输入名称，然后创建内容库。
. 打开您创建的内容库。
. 选择*操作* > *导入项目*，然后导入 OVA 文件。



NOTE: 有关详细信息，请参见 https://blogs.vmware.com/vsphere/2020/01/creating-and-using-content-library.html["创建和使用内容库"]。


NOTE: 在部署之前，请将集群分布式资源调度程序 (DRS) 设置为"保守"，以防止在安装期间进行虚拟机迁移。

ONTAP tools for VMware vSphere 最初部署为非 HA 配置。从 ONTAP tools 10.6 开始，默认情况下启用 CPU 热添加和内存热插拔。要稍后扩展到 HA，必须启用这些功能。

.步骤
. 从 https://mysupport.netapp.com/site/products/all/details/otv10/downloads-tab["NetApp 支持站点"^]下载 ONTAP tools OVA 文件和签名证书。如果您已将 OVA 导入内容库，请跳过此步骤。
. 登录到vSphere服务器。
. 转到要部署 OVA 的资源池、群集或主机。
+

IMPORTANT: 请勿将 ONTAP tools 虚拟机存储在其管理的 vVols 数据存储上。

. 从内容库或本地系统部署 OVA。
+
|===


| 从本地系统 | 从内容库 


| a.右键单击并选择*部署OVF模板...*。b.从URL中选择OVA文件或浏览到其位置，然后选择*下一步*。 | a.转到您的内容库并选择要部署的库项目。b.选择*操作*>*从此模板中新建虚拟机* 
|===
. 在*选择名称和文件夹*中，输入虚拟机名称和位置。
. 选择计算机资源，然后选择*Next*。(可选)选中*自动启动已部署的VM*复选框。
. 查看模板的详细信息，然后选择*Next*。
. 阅读并接受许可协议，然后选择*Next*。
. 为配置和磁盘格式选择存储，然后选择*Next*。
. 为每个源网络选择目标网络，然后选择*Next*。
. 在*自定义模板*窗口中，输入所需的值。 image:../media/custom-temp-p2.png["自定义模板"]
+
[IMPORTANT]
====
*自定义模板*页面上的值是成功部署所必需的。

特别注意以下字段：

** *主机名*：输入 ONTAP tools VM 主机名。请使用有效的主机名格式。
** *ONTAP tools IP address*：这是用于访问 ONTAP tools 的主要管理界面。
** *IPv4 address*：这是用于诊断 shell 和 SSH 访问以进行故障排除和维护的节点 IP 地址。


如果您为主机或 vCenter 使用 DNS 名称，请确保这些名称在 DNS 中正确解析。

====
+

NOTE: vCenter 主机名是部署ONTAP工具设备的 vCenter Server 实例的名称。

+
如果您在双 vCenter 服务器拓扑中部署 ONTAP tools，其中设备托管在一个 vCenter 实例中并管理另一个实例，请为托管 ONTAP tools 的 vCenter 实例分配受限角色。创建专用 vCenter 用户和角色，仅具有 OVF 模板部署所需的权限。有关详细信息，请参见 link:../concepts/rbac-vcenter-use.html#vsphere-object-hierarchy["适用于VMware vSphere 10的ONTAP工具附带的角色"]。

+
对于由 ONTAP tools 管理的 vCenter 实例，请确保 vCenter 用户帐户具有管理员权限。

+
** 主机名必须包含字母（A-Z、a-z）、数字（0-9）和连字符（-）。对于双栈，请指定映射到 IPv6 地址的主机名。
+

NOTE: 不支持纯 IPv6。混合模式支持包含 IPv6 和 IPv4 地址的 VLAN。

** ONTAP tools IP 地址（以前称为负载均衡器）是 ONTAP tools Manager 的外部端点(`\https://<ip>:8443/virtualization/ui/`）、API 调用以及从 vCenter UI 访问插件。
** ONTAP tools 虚拟 IP 地址（以前称为节点互连）分配给 Kubernetes API（kube-api）服务器，并充当 Kubernetes 控制平面的虚拟 IP。
** IPv4 地址是映射到指定主机名的节点管理地址，用于诊断 shell 和 SSH 访问。


. 查看*Ready to Complete*(准备完成*)窗口中的详细信息，选择*Complete*(完成*)。
+
部署任务启动时，进度会显示在 vSphere 任务栏中。

. 如果未选择自动开机，请在任务完成后启动 VM。


从虚拟机 Web 控制台跟踪安装进度。

如果 OVF 表单中存在差异，对话框会提示纠正措施。使用 Tab 键导航，进行所需的更改，然后选择 *OK*。您有三次机会来解决问题。如果三次尝试后问题仍然存在，安装将停止，您应在新虚拟机上重试安装。
