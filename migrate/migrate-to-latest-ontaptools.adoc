= 从 ONTAP tools for VMware vSphere 9.xx 迁移到 10.6
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
从 ONTAP tools for VMware vSphere 9.xx 迁移到 10.6 需要根据您的数据存储类型执行不同的步骤。

您可以从 ONTAP tools for VMware vSphere 9.12D1、9.13D2 和 9.13P2 版本迁移到 ONTAP tools for VMware vSphere 10.6。

如果您的设置有 NFS 和 VMFS 数据存储区，但没有 vVols 数据存储区，请卸载 ONTAP tools 9.xx 并部署 ONTAP tools 10.6。如果您的设置包含 vVols 数据存储区，请迁移 VASA Provider 和 SRA。

下表概述了这两种不同场景下的迁移过程。

|===
| *如果设置有 vVols 数据存储* | *如果设置仅包含 NFS 和 VMFS 数据存储* 


| 步骤：1.link:../migrate/sra-vasa-migration.html["迁移 VASA 提供程序"] 2.  https://techdocs.broadcom.com/us/en/vmware-cis/vsphere/vsphere/8-0/vsphere-storage-8-0/storage-policy-based-management-in-vsphere/creating-and-managing-vsphere-storage-policies.html["创建虚拟机存储策略"] | 步骤：1.从您的环境中删除 ONTAP tools 9.xx。请参阅  https://kb.netapp.com/data-mgmt/OTV/VSC_Kbs/OTV_How_to_remove_OTV_9_12_from_your_environment["如何从您的环境中删除 OTV 9.xx"]（位于 NetApp 知识库中）。2.link:../deploy/quick-start.html["部署和配置适用于 VMware vSphere 10.6 的 ONTAP tools for VMware vSphere"] 3.link:../migrate/sra-vasa-migration.html["更新 SRA"] 4. https://techdocs.broadcom.com/us/en/vmware-cis/vsphere/vsphere/8-0/vsphere-storage-8-0/storage-policy-based-management-in-vsphere/creating-and-managing-vsphere-storage-policies.html["创建虚拟机存储策略"] 
|===

NOTE: 从 ONTAP tools for VMware vSphere 9.xx 迁移到 10.6 后，使用 NVMe/FC 协议的 vVols 数据存储将变得不可操作，因为 ONTAP tools 10.6 仅支持将 NVMe-oF 协议与 VMFS 数据存储结合使用。



[[after-migration]]
== 迁移后

请验证以下信息：

* 数据存储库可从 vCenter 服务器访问。
* VM 存储策略按预期映射。
* 对于已配置的数据存储区，保护和复制状态显示为正常。
