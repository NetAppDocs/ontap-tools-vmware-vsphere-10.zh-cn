= 缩小 ONTAP tools 中的 vVols 数据存储库
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
从 ONTAP tools 中的 vVols 数据存储中删除卷，以便在不再需要额外存储时降低容量。

在 vCenter Server 中，对由ONTAP工具管理的任何vVols数据存储使用“从数据存储中删除存储”操作。

如果卷包含 vVols，则无法从该卷中删除存储；此类卷的删除选项已禁用。从数据存储中删除卷时，您还可以选择从 ONTAP 存储中删除选定的卷。


NOTE: 基于ASA r2 系统的vVols数据存储不支持缩小vVols数据存储操作。

.步骤
. 在vSphere Client主页中、选择*主机和集群*。
. 在导航窗格中、选择包含数据存储库的数据中心。
. 右键单击 vVol 数据存储区，然后选择 *NetApp ONTAP tools* > *Remove storage from datastore*。
. 选择没有vVols 的卷，然后选择“删除”。
+

NOTE: 用于选择 vVols 驻留的卷的选项已禁用。

. 在 *Remove storage* 弹出窗口中，选中 *Delete volumes from ONTAP cluster* 复选框以从数据存储和 ONTAP 存储中删除卷，然后选择 *Delete*。
