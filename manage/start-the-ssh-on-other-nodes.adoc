= 在其他 ONTAP tools 节点上启动 SSH
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在升级 ONTAP tools for VMware vSphere 之前，请在环境中的每个其他节点上启动 SSH。

.开始之前
为您的 vCenter Server 实例启用 VASA Provider 扩展。

.关于此任务
升级前，请对每个节点重复此步骤。

.步骤
. 登录到 vCenter 服务器。
. 找到 ONTAP tools 节点 VM 并启动 Web 控制台。
. 使用 `maint`凭据登录。
. 输入 `4`以选择*Support and Diagnostic*。
. 输入 `1`以选择 *Access diagnostic shell*。
. 输入 ... `y` 以继续。
. 运行命令 `sudo systemctl restart ssh`。
