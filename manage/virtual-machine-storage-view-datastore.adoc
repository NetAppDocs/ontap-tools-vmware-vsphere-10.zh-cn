= 在 ONTAP tools 中查看虚拟机存储详细信息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用存储视图可查看与虚拟机关联的 vVols。


NOTE: 此视图适用于至少有一个来自ONTAP tools for VMware vSphere管理的vVols数据存储的磁盘的虚拟机。

.步骤
. 从 vSphere Client 转到虚拟机。
. 在右窗格中选择*Monitor*选项卡。
. 选择 *NetApp ONTAP tools* > *Storage*。右侧窗格上将显示 *Storage* 详细信息。您可以查看虚拟机上的 vVols 列表。
+
您可以使用*管理列*选项隐藏或显示列。
