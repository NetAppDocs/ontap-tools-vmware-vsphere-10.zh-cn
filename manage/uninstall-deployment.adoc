= 卸载适用于 VMware vSphere 的 ONTAP tools 部署
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
卸载 ONTAP tools for VMware vSphere 会删除设备中的数据，因此请完成以下步骤以正常关闭部署并避免意外数据丢失。

.步骤
. 从适用于VMware vSphere托管的数据存储库的ONTAP工具中删除或移动所有虚拟机。
+
** 要删除虚拟机、请参见 https://techdocs.broadcom.com/us/en/vmware-cis/vsphere/vsphere/8-0/vsphere-virtual-machine-administration-guide-8-0/managing-virtual-machinesvsphere-vm-admin/adding-and-removing-virtual-machinesvsphere-vm-admin.html#GUID-376174FE-F936-4BE4-B8C2-48EED42F110B-en["删除并重新注册VM和VM模板"]
** 要将它们移动到非托管数据存储区，请参阅 https://techdocs.broadcom.com/["Broadcom 技术文档"]以了解有关使用 Storage vMotion 迁移虚拟机的信息


. link:../manage/delete-ds.html["删除数据存储库"]在适用于VMware vSphere的ONTAP工具上创建。
. 如果您已启用 VASA Provider，请在 ONTAP tools 中选择 *设置* > *VASA Provider 设置* > *注销*，以从所有 vCenter Server 实例中注销 VASA Provider。
. 从VMware Live Site Recovery中删除SRA适配器：
+
.. 以管理员身份使用端口5480登录到VMware Live Site Recovery设备管理界面。
.. 选择*存储复制适配器*。
.. 选择相应的SRA卡，然后从下拉菜单中选择*Delete*。
.. 确认您知道删除适配器的结果，然后选择*Delete*。


. 删除已载入到 ONTAP tools for VMware vSphere 的 vCenter Server 实例。请参阅 link:../manage/manage-vcenter.html["管理vCenter Server实例"]。
+
删除 vCenter Server 实例时，ONTAP tools 可以引导您完成所需的清理。如果在 *Remove vCenter* 对话框中出现提示，请选择 *Remove all storage artifacts from this vCenter Server* 和 *I understand that the associated datastores will no longer be managed by ONTAP tools*，然后选择 *Force delete*。

+
在使用*强制删除*之前，请确保已删除或迁移所有 vVols 数据存储区，所有受保护的数据存储区均已取消保护，并且未运行任何发现作业。

+
如果在删除过程中无法访问 vCenter 服务器，ONTAP tools 仅删除 vCenter 服务器记录。您必须从 VMware vCenter Server 手动注销插件。

. 从vCenter Server中关闭适用于VMware vSphere VM的ONTAP工具并删除这些VM。
