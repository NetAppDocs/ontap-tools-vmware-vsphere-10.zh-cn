= 适用于 VMware vSphere 的 ONTAP tools 报告
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP tools for VMware vSphere 插件提供报告，可帮助您监控由 ONTAP 存储支持的虚拟机和数据存储区。要查看报告，请在 vSphere Client 快捷方式部分中选择 ONTAP tools for VMware vSphere 插件图标，然后选择 *Reports* 选项卡。

虚拟机报告列出了在基于 ONTAP 存储的数据存储上至少有一个磁盘的已发现虚拟机，以及性能指标。展开虚拟机记录时，可以查看其磁盘的所有数据存储信息。

数据存储库报告列出了 ONTAP tools for VMware vSphere 发现的、使用 ONTAP 存储的数据存储库及其性能指标。

您可以使用*管理列*选项隐藏或显示列。
