= 将 VMware vSphere 主机添加到 ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
将新的 VMware vSphere 主机添加到 ONTAP tools for VMware vSphere，以便您可以管理和保护主机数据存储库。

.步骤
. 按照 https://techdocs.broadcom.com/["Broadcom 技术文档"]将主机添加到 VMware vSphere 集群。
. 添加主机后，请转到 ONTAP tools 主菜单，然后在概览面板中选择 *发现*，或等待计划的主机发现操作完成。


.结果
新主机现在由 ONTAP tools for VMware vSphere 发现和管理。您现在可以在主机上管理数据存储库。
