= 重置ONTAP工具管理器密码
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您忘记了ONTAP工具管理器密码，可以使用从ONTAP tools for VMware vSphere维护控制台生成的重置令牌来恢复管理员访问权限。

.步骤
. 打开网页浏览器并导航至 `https://<ONTAPtoolsIP>:8443/virtualization/ui/`访问ONTAP工具管理器。
. 在登录页面，选择“重置密码”。
. 使用ONTAP tools for VMware vSphere维护控制台生成密码重置令牌：
+
.. 登录到 vCenter 服务器。
.. 找到 ONTAP tools 虚拟机并启动 Web 控制台。
.. 使用 `maint`凭据登录。
.. 进入 `2`选择“系统配置”。
.. 输入 `3`以选择 *Generate token to reset manager UI password*，并记下令牌。


. 在密码重置对话框中，输入重置令牌、用户名和新密码。
. 选择“重置”以更新凭据。
. 使用新密码登录ONTAP工具管理器。
