= 在 ONTAP tools 中卸载 NFS 和 VMFS 数据存储区
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用此任务可从 ESXi 主机卸载 NFS 或 VMFS 数据存储区。UI 或 API 不支持集群级数据存储卸载。

从 ONTAP tools 10.6 开始，受保护的 VMFS 数据存储区将阻止卸载操作。

.步骤
. 登录到vSphere Client。
. 右键单击 NFS 或 VMFS 数据存储对象并选择 *卸载数据存储*。
+
vSphere 客户端打开一个对话框，列出挂载数据存储库的 ESXi 主机。如果数据存储区受到保护，ONTAP tools 会阻止该请求并显示一条消息，提示该数据存储区受到保护且无法卸载。

. 选择一个或多个ESXi主机以卸载数据存储库。
+
您无法从所有主机卸载数据存储库。用户界面建议改用删除数据存储库操作。

. 选择*Unmount*按钮。
+
*卸载数据存储区*选项仅在主机移出受保护的主机群集时可用。




NOTE: 如果数据存储区受到保护，则必须先取消保护，然后才能卸载它。

.下一步是什么？
您可以在近期任务面板中跟踪进度。
