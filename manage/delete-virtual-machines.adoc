= 在 ONTAP tools 中清理 VASA 配置
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
按照以下步骤在 ONTAP tools 中完成 VASA 清理。


NOTE: 在开始 VASA 清理之前，请删除所有 vVols 数据存储区。

.步骤
. 打开 `\https://OTV_IP:8143/Register.html`以注销插件。
. 确认此插件在vCenter Server上不再可用。
. 关闭 ONTAP tools for VMware vSphere 虚拟机 (VM)。
. 删除适用于VMware vSphere VM的ONTAP工具。
