= 在 ONTAP tools 中挂载 vVols 数据存储库
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
将 VMware 虚拟卷（vVols）数据存储区挂载到一个或多个其他主机以扩展存储访问。只能通过主机级 API 卸载 vVols 数据存储区。不支持集群级数据存储区卸载。


NOTE: 添加主机后，等待计划的主机发现完成后，它才会显示在 ONTAP tools 中。或者，您可以从 NetApp ONTAP tools 概述屏幕手动运行发现。有关将 ESXi 主机添加到 vSphere 集群的信息，请参阅 https://techdocs.broadcom.com/["Broadcom 技术文档"]。

.步骤
. 在vSphere Client主页中、选择*主机和集群*。
. 在导航窗格中、选择包含数据存储库的数据中心。
. 右键单击该数据存储库并选择* NetApp ONTAP tools*>*挂载数据存储库*。
. 在*在主机上挂载数据存储库*对话框中，选择要挂载数据存储库的主机，然后选择*挂载*。


最近任务面板会显示进度。
