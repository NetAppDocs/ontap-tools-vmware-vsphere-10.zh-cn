= 在 ONTAP tools 中管理集群配置
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用此任务可以在 ONTAP tools 中查看、编辑和删除主机集群配置设置，以便为主机集群保护保持站点分配的准确性。

.开始之前
* 请确保您在 vSphere 中具有管理权限。
* 确保您的 ONTAP tools 用户帐户具有管理主机集群保护设置的权限。


.步骤
. 在 ONTAP tools 插件中，导航到 *Protection* > *Cluster protection configuration*。
+
主机集群配置设置及其配置类型、SVM 和主机均已列出。

. 选择要管理的主机集群配置设置旁边的垂直省略号（三个点）：
+
.. 要编辑配置，请选择 *Edit* 并更新所需的设置。有关详细信息，请参阅 link:../protect/config-proximity.html["使用 ONTAP tools 配置用于数据存储保护的集群"]。
+
将新主机添加到集群时，现有集群配置设置不会自动应用于该主机。编辑现有集群配置并将新主机分配给相应的站点。

.. 要删除配置，请选择 *Remove* 并在对话框中确认删除。
