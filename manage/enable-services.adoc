= 在 ONTAP tools Manager 中启用可选服务
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用 ONTAP tools Manager 启用可选服务，如 VASA Provider、vVols 配置导入和灾难恢复 (SRA)。

.步骤
. 从Web浏览器启动ONTAP工具管理器： `\https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. 使用您在部署期间提供的适用于VMware vSphere的ONTAP工具管理员凭据登录。
. 在*概述*部分，选择*编辑设备设置*。
. 在 *Services* 部分，启用所需的可选服务，例如 VASA Provider、vVols 配置导入和灾难恢复 (SRA)。
+
首次启用这些服务时，请创建 VASA Provider 和 SRA 凭据。

+
** 使用这些凭据在 vCenter Server 上注册和启用 VASA Provider 和 SRA 服务。
** 此用户名只能包含字母、数字和下划线。
** 密码长度必须介于 8 到 256 个字符之间。





NOTE: 在禁用任何可选服务之前，请确保由 ONTAP tools 管理的 vCenter Server 实例不使用该服务。

+ *允许导入 vVols 配置*选项仅在启用 VASA Provider 服务时显示。此选项支持将 vVols 数据从 ONTAP tools 9.x 迁移到 ONTAP tools 10.6。
