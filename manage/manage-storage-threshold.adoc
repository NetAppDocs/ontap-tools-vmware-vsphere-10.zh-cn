= 在 ONTAP tools 中管理存储阈值
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以设置存储阈值，以便在卷或聚合容量达到一定级别时在 vCenter Server 中接收通知。

.步骤
. 登录到 vSphere 客户端。
. 在*快捷方式*页面上，选择*插件*部分中的* NetApp ONTAP tools*。
. 在ONTAP工具的左侧窗格中，转到 *设置* > *阈值设置* > *编辑*。
. 在*编辑阈值*窗口中，在*近满*和*满*字段中提供所需的值，然后选择*保存*。
+

NOTE: 您可以将阈值恢复为建议的默认值：近满为 80，满为 90。
