= ONTAP tools 中数据存储的 ONTAP 存储视图
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP tools for VMware vSphere 在*配置*选项卡上显示数据存储及其卷的 ONTAP 端详细信息，包括每种数据存储类型的存储后端、聚合和卷详细信息。

.步骤
. 在 vSphere Client 清单中，选择数据存储库。
. 在右窗格中选择*Config*选项卡。
. 选择 * NetApp ONTAP工具* > * ONTAP存储*。视图会根据数据存储类型而变化。请参见下表：


|===


| *数据存储库类型* | *可用信息* 


| NFS 数据存储库 | *存储详细信息*页面包含存储后端、聚合和卷信息。*NFS 详细信息*页面包含与 NFS 数据存储区相关的数据。注意：如果在 ONTAP tools 之外更改了 nconnect 值，ONTAP tools 中显示的值可能不会反映该外部变化。 


| VMFS数据存储库 | *存储详细信息*页面包含存储后端、聚合、卷和存储可用区 (SAZ) 详细信息。*存储单元详细信息*页面包含存储单元的详细信息。 


| 数据存储库 | 该页面列出了所有卷。您可以从 ONTAP 存储窗格中扩展或删除存储。ONTAP tools for VMware vSphere 不支持基于 ASA r2 系统的 vVols 数据存储区的此视图。 
|===
.结果
您可以根据选定的数据存储区类型查看 ONTAP 端数据存储区详细信息。
