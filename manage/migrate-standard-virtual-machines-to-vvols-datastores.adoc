= 将虚拟机迁移到 ONTAP tools 中的 vVols 数据存储库
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以将虚拟机从 NFS 或 VMFS 数据存储区迁移到 Virtual Volumes (vVols) 数据存储区，以使用基于策略的 VM 管理和其他 vVols 功能。

.开始之前
验证 VASA Provider 未在计划迁移的任何虚拟机上运行。如果将运行 VASA Provider 的虚拟机迁移到 vVols 数据存储区，则无法执行任何管理操作，包括打开 vVols 数据存储区上的虚拟机的电源。

.关于此任务
当您从 NFS 或 VMFS 数据存储迁移到 vVols 数据存储时，vCenter Server 使用 vStorage APIs for Array Integration (VAAI) 卸载从 VMFS 数据存储移动的数据，但不卸载从 NFS VMDK 文件移动的数据。VAAI 卸载通常可减少主机负载。

.步骤
. 右键单击要迁移的虚拟机，然后选择*Migrate*。
. 选择*仅更改存储*，然后选择*下一步*。
. 选择虚拟磁盘格式、虚拟机存储策略以及与要迁移的数据存储区的功能相匹配的 vVol 数据存储区。
. 查看设置并选择*完成*。
