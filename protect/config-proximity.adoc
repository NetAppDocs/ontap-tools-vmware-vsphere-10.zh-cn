= 使用 ONTAP tools 配置用于数据存储保护的集群
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用 ONTAP tools for VMware vSphere 配置集群配置（主机到存储的邻近性）设置，从而为您的虚拟化环境实现高效的数据存储保护和简化的故障转移管理。

.开始之前
* 请确认您在 vSphere 中具有管理权限。
* 集群配置设置适用于统一和非统一配置，而访问设置仅适用于 AFD 类型的关系。


.步骤
. 在 vSphere 客户端，右键单击主机集群，选择*配置集群保护*。
+

NOTE: 如果集群已具有集群配置，此选项用于编辑现有配置。

. 在*配置类型*窗口中：
+
.. 选择*统一*以允许两个故障域中的主机访问两个站点的存储资源。故障域是一组硬件和基础架构组件。将每个主机分配给两个站点的故障域。
.. 选择*Non-uniform*以限制每个站点的主机仅访问其各自站点的存储。相应地将主机分配给故障域。
.. 输入故障域名。默认名称为"Site A"和"Site B"。您可以编辑这些值。站点名称映射到源和目标故障域。UI 在您键入时验证条目，并显示不支持的字符或超出字符限制的值的消息。
+

NOTE: 配置类型设置后便无法修改。要更改配置类型，请删除群集配置，然后创建具有所需设置的新配置。



. 选择 * 下一步 * 。
. 在*主机*窗口中，将每台主机分配给源故障域或目标故障域。必须分配所有主机，且主机不能同时属于两个站点。向导中显示的站点名称是源和目标故障域名称。分配所有主机后，*下一步*按钮将变为可用。
. 选择 * 下一步 * 。
. 在 *Storage SVM peers* 页面上，将每个 SVM 分配给相应的站点。您可以分配多个 SVM 对等体，但每个站点必须至少分配一个。将 SVM 分配给站点时，其对等 SVM 将自动分配给相反的站点。
. 选择 * 下一步 * 。
. 查看*摘要*页面。确认相应故障域的集群配置设置。
. 选择*Create*以应用配置。
. 要查看或编辑现有集群保护配置：
+
.. 转到 ONTAP tools 插件视图。
.. 导航到*保护* > *集群保护配置*。
.. 选择集群以查看其当前配置。
.. 单击垂直省略号并选择 *Edit* 以修改配置。向导将显示当前设置以供编辑。
+
image:../media/edit-protection.png["编辑集群保护配置"]





.结果
配置已应用，您可以在 ONTAP tools 插件中查看或编辑该配置。
