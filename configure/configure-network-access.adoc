= 在 ONTAP tools 中配置网络访问
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
默认情况下，除非您配置网络访问，否则 ONTAP tools 会自动将从 ESXi 主机发现的所有 IP 地址添加到导出策略。您可以修改导出策略以仅允许从特定 IP 地址进行访问；对于排除的 ESXi 主机，挂载操作将失败。

.步骤
. 登录到vSphere Client。
. 在插件部分下的快捷方式页面上选择 *NetApp ONTAP tools*。
. 在ONTAP工具的左侧窗格中，转到 *设置* > *管理网络访问* > *编辑*。
+
要添加多个 IP 地址，请用逗号、范围、无类域间路由 (CIDR) 表示法或三者的组合分隔列表。

. 选择 * 保存 * 。
