= 在 ONTAP tools 中将存储后端与 vCenter Server 实例关联
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用此任务可将全局存储后端与 vCenter Server 实例关联。全局存储后端是在 ONTAP tools Manager 中添加的后端，尚未与特定 vCenter Server 实例关联。对于 NetApp MetroCluster 配置，当您关联存储后端集群时，还需将其对等集群与 vCenter Server 关联。

.步骤
. 从Web浏览器启动ONTAP工具管理器： `\https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. 使用您在部署期间提供的适用于VMware vSphere的ONTAP工具管理员凭据登录。
. 从侧栏中选择vCenter。
. 选择要连接到存储后端的 vCenter Server 实例旁边的垂直省略号。
. 从下拉菜单中，选择要与所选 vCenter Server 实例关联的存储后端。
